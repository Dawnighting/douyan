## 管理端用法

1. 打开 `admin.html`，用云开发里创建的用户名密码登录；
2. 「积分登记」：先选/新建赛事 → 输入成员名字 + 积分 → 回车继续下一条；
3. 多人成绩可粘贴到「批量导入」，每行 `名字 积分 [备注]`；
4. 「成员」「老师」可增删改；「兑换」审核通过后自动扣积分；
5. 「数据」可导出全部数据 JSON，用于备份或迁移到新环境。

## 迁移到俱乐部自己的云环境

1. 用俱乐部账号新建 CloudBase 环境，创建 5 个集合并配置安全规则（UID 换成俱乐部管理员）；
2. 修改 `js/config.js` 的 `envId`、`adminUid`；
3. `git push` 即可；如需保留数据，用管理端导出的 JSON 迁移。
